# 根外共享源码软链接

默认保持原有安全策略：仓库内源码正常读取；指向仓库外的软链接不允许读取。
若工程主动使用根外共享源码，可在启动 CodeGraph 时指定可信源码目录：

```bash
export CODEGRAPH_ALLOWED_SOURCE_ROOTS="$(realpath /work/shared-source)"
codegraph init
codegraph sync
codegraph serve --mcp --path /work/project
```

- 多个目录：Linux/macOS 用 `:` 分隔，Windows 用 `;` 分隔。
- 填写现有目录的绝对真实路径，不接受相对路径或软链接别名。不要授权整个用户目录或磁盘；系统根和部分敏感目录会被拒绝。
- 工程必须已有指向该目录的软链接。本选项不添加扫描目录，不允许直接通过 `../` 或根外绝对路径读取文件，也不改变 ignore/language 规则。
- 每次读取仍检查最终真实目标。可信目录内再次链接到未授权目录的文件仍被拒绝；目录名前缀相同不算授权。
- 索引、手动同步和源码查询必须使用相同配置。MCP 客户端应将变量写入服务端进程的环境；共享服务/daemon 应停止后带此变量重新启动，已有常驻进程不会接收 shell 后续的环境变更。
- 外链目标内的修改不能依赖现有 watcher 自动感知，请显式执行 `codegraph sync`。本次修复不更改 watcher、原有 stdio/共享服务模式或数据库归属。
- 未授权的根外软链接仍会导致对应文件读取失败；本选项不解决权限不足、扫描失败清理旧数据等其他问题。

该设置允许 CodeGraph 对指定目录中的源码进行索引和返回源码内容，应只填写有权读取且愿意向当前客户端提供的源码目录。
